## ルール

### 1. ゲームの目的と勝利条件
* **ゲーム勝利条件**：相手の国家カードを3国撃破させたら勝利。

### 2. デッキ構築と基本方針
* プレイヤーは「協商国デッキ」または「中央同盟国デッキ」のいずれかを選ぶ。
* **中立・IFカード**：「中立国（IF）」タグを持つカード（ポーランド、リトアニアなど）は、両陣営どちらのデッキにも組み込むことができる。
* **国力基準値**：ドイツ帝国の初期能力（人的100 / 工業100 / 資源100）を絶対的な「100」の基準とし、他国の数値を相対評価
* その国の降伏限界値(20)
* 国家形成をすると、降伏限界値が高まる。

### 3. 戦場・エリアの構成
* **メインエリア**：主力として戦場に立つ国家カードを置く場所。
* **サブエリア**：サブになるカードを置く場所。
* **山札**：デッキは50枚
* **兵士カード山札**：お互い10枚 デッキには含まない すべて性能は同じである
* **墓地**：手札を捨てたりするところ
* **手札**：自分の手札 後攻は3枚多くゲームスタート
* **補給（システム）**：兵士が存在。行動や戦闘で減少し、50%未満になると弱体化する。

### 4. 兵士
* 自分のターンのはじめに2体まで兵士を召喚できる。
* 兵士召喚には、コスト人的10 工業10 資源10がかかる。
* 同時に10まで召喚できる。
* ステータスは補給
* 補給は10が限度で、召喚したときは10ある
* 攻撃するときには、補給は1減る
* 作戦を行うときは、そのカードに書かれたコスト分

### 5. バトルの方式

#### ゲーム開始時の準備
1. じゃんけんとかで先攻後攻を決める
2. 自分のデッキの中から、国家カードを一枚選んでメインエリアに置く。
3. デッキをシャッフル（以下山札）して山札から5枚引いて手札にする。
4. 後攻は8枚引ける。

#### ターンの流れ（俺のターン ドロー！！）
1. カードを一枚引く
2. メインエリアのカードは最大ステータスの25%、SP以外を回復する  
3. サブエリアのカードは最大ステータスの15% SP以外を回復する
4. 兵士を召喚するか決める(0~2)最大10まで
5. 兵士の補給を回復するか決める  
   メインエリアのカードの人的と工業と資源を3ずつ減らすと兵士一体の補給が1回復する。どの兵士をどのくらい回復するかは自由で、回復しなくてもよい
6. サブエリアに空きがあれば、好きな国家カードを選んで出してもよい
7. 作戦政治カードを合計3枚まで使用してもよい 作戦カードは表向きでおいて置く。どの兵士で攻撃するかを宣言する。
8. 先に作戦政治カードの処理を行う。順序は自由でよい
9. 兵士カードで攻撃を行ってもよい。兵士一体で、基礎攻撃力2にすべてのバフを加算して小数点第一位で切り上げた値を相手の兵士一体に与え、相手の補給ゲージを減らす。兵士カードで攻撃を行った後は、補給-1にすべてのデバフを加算した値をその兵士に与える。もし相手の兵士の数が自分より上回っていて、総補給も上回っていたら、相手の国家カードに直接攻撃ができる。相手のSPを5減らす。バフで上乗せできる。SPが0になったら、専用作戦カードで撃破ができる。
10. 相手のターンを繰り返して、3体倒した方の勝ち。
