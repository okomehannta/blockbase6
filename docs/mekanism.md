## mekanism
作りかけ記事
最終更新261127

minecraft1.20.1におけるmekanismを解説します
公式アドオン　mekanism generatorが入っている前提で解説します
##概要
バージョン1.7.10~1.21.1
##配布サイト
https://www.curseforge.com/minecraft/mc-mods/mekanism

大規模な工業mod 
鉱石5倍や核融合発電まで楽しめます
no1神modだと思う

##進め方（デジタルマイナーまで）
レッドストーン
オスミウム（水色っぽい感じ　どこにでもあって　石つるはしで掘れる）
鉄
ダイヤ
石炭または木炭

を結構たくさん用意しましょう
オスミウムは装備に使えます　かなり強いです（公式アドオン　mekanism tools　導入時）
パクセルはつよい


冶金注入機
熱発電機

を作って、熱発電機の周りにマグマを置いて、冶金に鉄とレッドストーンや、石炭を加えるといろいろなものができる
鉄+レッドストーン　= 吹込合金
鉄+木炭または石炭  = 濃縮鉄
濃縮鉄+木炭または石炭 =　鋼鉄の粉
オスミウム+レッドストーン = 基本回路

そのあと

濃縮室
基本ユニバーサルケーブル

を作る
濃縮室は原石3を粉4（焼くとインゴット）にできる
また鉱石1を粉2にできる
超重要　レッドストーン　＝　濃縮レッドストーン
        石炭　　　　　　＝　濃縮炭素
        ダイヤモンド　 ＝　濃縮ダイヤモンド
        黒曜石　　　　　＝　黒曜石の粉4
濃縮にすると冶金のクラフトにおいて例えば吹込み合金を8作るとき
レッドストーン8と鉄8がいりますが
濃縮にすると
濃縮レッドストーン1と鉄8で作れます
冶金に入れる際は何でも濃縮しましょう

基本ユニバーサルケーブルは
熱発電機で作った電力を輸送することができます。
熱発電機の緑色の面とつなげましょう

そのあと

オスミウム圧縮機
風力発電機2
エネルギーアップグレード8
石置換アップグレード
基本ティアアップグレード

を用意して、

冶金　
黒曜石の粉+ダイヤ　＝　精製黒曜石の粉
オスミウム圧縮
精製黒曜石の粉　+　オスミウム　＝　精製黒曜石インゴット

これで攻撃21の充電型即時破壊ツールの原子分解機の材料が整うはず
絶対に作りましょう
あと精製黒曜石インゴットは装備にするとネザライト以上に強いです（mekanism tools 導入時）

アップグレードはあとで使います
基本ティアアップグレードはしゃがんで冶金を右クリックすると使えます
枠が3枠に増えます


ここまで揃ったらjeiを駆使してデジタルマイナーを作りましょう
できたらさっき作ったアップグレードを全投入
エネルギー面は表裏ありますが
片方に風力発電機を直につける
もう片方はエネルギーケーブルを伸ばしていろいろ電力を消費する機会を置いたりほかの発電機を置いたり
電力が足りない場合はほかの機械にエネルギーアップグレードを積みましょう
これができればあとは鉱石が無限になります
電力に余裕が出てきたら、スピードアップグレードも積みましょう
またこのアイテムの中間素材の中間素材のパーソナルチェストは非常に強力です
立ったまま開けるシュルカーボックスです

##進め方（鉱石5倍化まで）
鉱石を5倍化したいところですが電力がないです
なのでガス発電機を作りましょう
以下を用意

ガス発電機
基本加圧チューブ
加圧反応室
電解分離機
粉砕機
基本物流トランスポーター
大量の作物または無限化した作物が入った入れ物系（チェストetc）
基本メカニカルパイプ
電動ポンプ
基本化学タンク

粉砕機
作物系　→　バイオ燃料

電解分離機
水　→　水素　+　酸素

加圧反応室
バイオ燃料+水+水素　＝　基質+エチレン

ガス発電機
エチレン→電力

基質はゴミです
終盤までいりません
ガス発電機は水素を入れて発電することもできますが
発電量が少なく電解分離機稼働コストよりも下回るので
意味ないです
エチレンはストックできる基本化学タンクに入れておくといいかもしれません
水は電動ポンプで吸い上げます
間違ったものを入れたら　スポイト　を使いましょう
さっき出てきたレシピ以外のものはエチレン無限化用です
